## 模型服务阻塞与交付要求

用户提供的测试 Key 在本机向 DeepSeek 官方
`https://api.deepseek.com/models` 发起只读 Bearer 请求时返回 HTTP `401`。
该 Key 未被写入仓库。由于没有课程中转/校园网关的 Base URL、协议和模型 ID，
不能把四项连接信息中的任意一项猜成事实。

开课前必须由课程负责人提供并验证：

1. 有效 Key；
2. Base URL；
3. API 协议；
4. 模型 ID。

在这些信息补齐前，代码、环境说明、插件安装和拦截逻辑可验收；Pi/DSH 的真实
模型问答无法宣称通过。
